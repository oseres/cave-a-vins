# Ma cave à vins

Application web simple de gestion de cave à vins, sans framework ni serveur.

## Fonctionnalités

- Ajouter, modifier et supprimer un vin
- Nom, appellation, millésime, couleur, conditionnement et quantité
- Conversion automatique des caisses de 6 ou 12 en nombre de bouteilles
- Recherche dans les vins
- Statistiques de la cave
- Persistance locale avec `localStorage`
- Interface responsive mobile et ordinateur

## Utilisation

Ouvrez simplement `index.html` dans un navigateur moderne. Les données sont stockées localement dans le navigateur utilisé.
